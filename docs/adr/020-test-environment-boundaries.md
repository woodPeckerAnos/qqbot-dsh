# ADR-020：测试环境的查询、执行与交付边界

状态：已批准，已实施。补充 ADR-017/019；持久 Task 保留 schemaVersion 3。

任务查询新增版本化紧凑投影与分段正文读取。默认 8 条、上限 20 条，同会话同代次；序列化响应最多 48 KiB，显式标注省略。64 KiB 传输限制继续保留。完整持久快照只用于服务内部与历史兼容查询。

前台最多 5 次模型调用、90 秒，最后一次无工具收尾。纯进度无派发权限，历史失败业务重跑绑定当前用户的明确重试请求，失败材料默认只展示摘要。原任务不会重新执行，结果整理的既有有限重试保留。

worker 工具阶段最多 40 个根与子代理共用 step，另保留根 worker 一次无工具收尾；默认 24 分钟开始收尾、30 分钟硬截止。主服务持有执行预算，插件限制工具并投递收尾消息。失败确定后仍收集同一执行的关闭材料，取消及迟到结果不改变既定终态。

搜索 HTTP 由主服务适配器执行；搜索服务独占串行队列和首次额度耗尽错误。明确月度耗尽缓存到进程退出，后续同服务请求复用原错误，不发 HTTP、不自动恢复。普通服务错误最多读取 3 个用户提供或本次获得的链接。额度耗尽不允许当前任务抓取或 bash 替代搜索；其他无需此搜索服务的任务保留能力。

引用由问题台账与消息窗口解析，判定 evidence 不进入引用正文。文本格式由 ReplyPolicy 显式传递，完整正文先转换再切分，代码内容保留。用户未要求正文文件时不发送 txt/md 等正文副本；图片独立分类，单图直接发送，多图与正文合并转发，其他资料最多一份 ZIP 独立上传。规范路径去重，不按内容哈希合并不同用途的文件。

管理员命令只匹配顶层文本，排除引用。主动判定关闭 reasoning 并限制输出；终态日志记录分类、原因类别与 errorId，不记录用户正文。离线 benchmark 使用生产执行路径、注入依赖及真实文件；live 入口独立，付费模型运行与部署需另行授权。

本次验证：`npm run check` 通过 1583 项离线测试和 42 个契约示例；独立本机 WebSocket 集成测试 108 项通过；V3 v2 benchmark 的 F01–F19、173 项检查及 98 个必需检查全部通过。生成报告写入 `tmp/benchmarks/tasks-v3-v2/`，历史 v1 报告保留。live 场景已准备，未请求真实模型，测试容器未重建或部署。
