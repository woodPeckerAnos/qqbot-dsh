# ADR-003：生产模块契约与机器边界

状态：已实施（2026-11-03）。行为基准为 ADR-001、ADR-002；本决策不增加配置、命令或部署入口。

## 决策

跨模块值类型、常量、错误和接口由独立私有 workspace `@qqbot/contracts` 定义。包不引用 `src`；接口声明和结构化元数据生成 `docs/MODULE-CONTRACTS.md`。维护者拥有契约，消费者兼容基线与 normal、edge、failure 示例随源码提交。

生产模块为配置、内容、连接器、存储、媒体、Runtime、Task、投递、Ingress、主动介入、谷时段及可观测性。每个模块以公共入口和契约类型工厂提供能力。同模块可以直接协作；跨模块禁止实现深层引用、实现类类型泄漏、未声明依赖和运行时依赖环。检查解析 TypeScript 模块解析结果、导入、再导出、require 及动态导入；不使用存量 ESLint 抑制基线。

TaskLifeCycleManager 是执行状态唯一写者，MessageQueue 是投递状态唯一写者。预算、Actor generation、调度额度、Runtime 租约、主动话题与统计分别由所属所有者修改。持久化的读取能力与写入能力分离，写入命名空间绑定所有者。准备候选值、成功持久化、提交内存、发布事件及结算按此顺序执行。平台动作发生后的保存失败保留未知结果，不能重发。

所有读取快照深只读且隔离内部引用，集合和字节数据有专门复制与只读处理。Runtime 只返回只读租约身份及操作能力；busy 与子代理集合属于池，不允许 runner 直接写记录。跨边界失败有稳定分类、重试语义和根因关联；兼容层保留媒体降级、保守话题回退和发送不重试。

异步能力声明身份、顺序、幂等键、通知次数、退订、关闭和时效。文件、网络、子进程能力由契约声明，并限制到模块能力入口。健康端点与字段保持兼容。

## 验证与兼容

`npm run check` 与 CI 检查契约独立编译、文档确定性、消费者兼容性、模块边界、单写者、可执行示例及独立离线冒烟。反向测试验证规则会拒绝违规。状态性质测试使用固定种子，金标准使用固定时钟和 ID，持久化故障验证不能留下可调度半成品。

只允许向后兼容增加；破坏性变更先添加版本化入口，迁移消费者后才移除旧入口。现有记录仍可读取，新增错误元数据可选。构建先编译契约包再编译应用；Docker 安装和运行时同时保留 workspace 清单、链接与产物。唯一生产入口仍为 `src/main.ts`，真实 WebSocket 单列集成检查。

## 历史与实施记录

此前的手写模块契约见本决策之前的 git 版本；历史测试夹具保留在 `tests/legacy`，包括旧可写 RuntimeEntry。

独立契约包和 12 个公共模块入口已落地。工厂与实现函数在契约包中导出签名类型，由生产公共入口提供运行值，避免声明不存在的运行时导出。初始 v1 消费者基线保存完整编译声明图，日常构建不改写基线；基线变更必须由维护者按版本协议审阅。

状态候选提交、只读身份租约、集合与字节深快照、统计记录接口及类型化失败已迁移到生产路径。发送前保存失败不执行平台动作，发送后保存失败只补写终态。超时和重启恢复保留未知结果、不重发。预算保存失败和未创建 Task 的孤立预留由既有维护循环补结算；JSONL 追加失败可能已有部分写入，要求核查后补写。

本次验收：

- `npm run check` 通过：52 个测试文件、1024 项通过；40 项 WebSocket 用例按既有规则留给独立集成检查。覆盖固定种子性质、固定时钟与 ID 金标准、持久化故障、52 项边界正反用例、16 项兼容反向测试和消费者类型拒绝用例。
- 12 模块的 36 个 normal/edge/failure 示例及独立离线冒烟全部通过；生成文档无漂移，契约独立编译、类型、lint、格式、兼容与覆盖门槛通过。未增加 ESLint 抑制项，只删除已失效旧项。
- `npm run test:integration` 通过：3 个文件、104 项通过，包含上述 40 项独立 localhost WebSocket 用例，不连接部署客户端或真实模型。
- 应用与契约 workspace 构建通过；契约包在没有 dist、生产代码或应用 workspace 链接的独立目录中编译并导入通过。Docker 运行阶段的相对 workspace 链接、契约产物和 12 模块解析通过。本机 Docker daemon 未启动，未实建镜像；CI 保留镜像构建并验证镜像内包解析。
- 回查现行配置、命令、平台字段、健康字段、持久化读取兼容性与唯一入口，未增加产品配置或改变 SessionActor、双 lane、独立投递及部署形态。
