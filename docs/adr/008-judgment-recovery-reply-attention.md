# ADR-008：判定恢复与回复提醒意图

状态：已实施（2026-11-07）。业务验收使用离线注入验证，真实 localhost WebSocket 独立检查；不新增真实模型调用。

## 背景与证据

话题判定的小 token 上限可能被推理消耗；主动判定遇到瞬时网络错误会立即失败，失败回调和 watcher 重复计数，暂停后无法自动恢复。实际 wait 提示缺少可回抄的完整问题 ID，唤醒路径存在补猜目标。主动快答已交付后，慢失败仍补发错误正文；普通群回复自动提及作者。b4d70d53、a886db8e 的具体工具根因仍未确认，不把追踪摘要缺失当作工具未收口。

## 决策

话题普通及聊天记录判定显式使用 reasoning_effort=none，分别保留 32/48 token 上限；失败保守回退相关，不吞输入。诊断只记录请求/响应模型、HTTP 状态、finish_reason、正文/推理长度和失败分类，不记录原文。

Chat 与主动判定增加可选结构化结果，保留 complete、judge 和 onError 兼容入口。网络异常、HTTP 408/429/5xx 最多三次请求，退避 250ms、1000ms；429 优先采用总超时预算内 Retry-After。整个调用共享一个总超时及一个并发名额；解析、响应契约及其他 4xx 不重试。一次最终失败只通知一次，生产失败计数和 warn 由 watcher 写入。

连续判定失败达到现有默认阈值三次后冷却五分钟，仍记录旁听。时间到期不主动调用模型，下一次有候选的有效触发放行一个试探；成功清零恢复，失败重新冷却。所有入口包括 wait 唤醒共享闸门。健康快照增加失败分类、重试总数和每会话的熔断状态、原因、暂停时间及下次试探时间。熔断状态保存在内存。

提示与引用验证共用候选快照，列出每个完整 q:<id>，唤醒提示给出目标及已等待时间。采纳前复核实时台账，缺失、伪造、已关闭分别诊断，不猜目标、不算上游失败。wait 票据每张只结算一次。

主动 Task 慢 lane 失败的反馈新增例外：快 lane 成功，至少存在一段原始正文，且全部原始正文均 sent 时，仅抑制慢错误正文。失败状态和诊断保留，附件及必需说明继续交付；其他情况和用户 Task 仍反馈真实原因。查询失败、工具未收口、空结果分别表述，不宣称任务已执行成功。

所有长度的普通回复取消自动 @，保留原消息引用。只有模型明确需要强烈定向提醒时可在最终正文首行输出内部标记 [REPLY_ATTENTION:strong]；runner 去除标记并生成内部 attention 意图。只允许提及当前 Task 的真实原消息作者；无真实引用不 @，附件与后续分段不重复 @。此规则取代 ADR-007 中普通群交付自动提及作者的历史决策。

工具结果使用安装 DSH 的 message.content[].toolCallId，与 message.source.callId 核对；业务收口和追踪分别验证。SessionActor 准入、双 lane 独立调度、TaskLifeCycleManager 执行状态所有权及 MessageQueue 投递状态所有权不变，不引入整轮会话锁。

## 验收与上线

离线注入 fetch、DSH、连接器和时钟，覆盖两种话题请求、元数据隐私、重试/预算/并发、冷却/试探/wait 闸门与票据守恒、目标引用时效、慢失败抑制边界、真实工具事件和提醒标记。完成 npm run check，真实 localhost WebSocket 单列 npm run test:integration。模型路由沿用现有配置及用户 reasoning_effort=none 实测证据。上线需重建镜像并重启，观察话题降级、失败计数一致性、熔断恢复及无效 wait 引用比例。

2026-11-07 验收结果：`npm run check` 通过，58 个测试文件、1,216 项通过、44 项跳过；类型、契约、边界、兼容、lint、格式、36 个公共入口冒烟及 Docker 包解析检查通过。`npm run test:integration` 通过，3 个测试文件、108 项通过。`git diff --check` 通过。未验证真实模型行为及 QQ 客户端展示，未部署；上述两个历史任务的具体工具根因仍未确认。
