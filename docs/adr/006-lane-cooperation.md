# ADR-006：双 lane 消息插入与语义协作

状态：已实施（2026-11-07）。取代 ADR-001 的入队正文去重和执行后静默限制；ADR-005 的坏样本继续作为裁判校准。

## 决策与契约

双 lane 保持独立调度。TaskSystem 聚合同 Task 的快执行状态、原始正文投递状态及成功送达分段，提供深只读协作快照。分段按入队顺序保留，以消息 ID 和递增更新水位去重；提醒、附件说明和失败通知不冒充原始正文。

复用 fd 3，消息绑定 taskId、executionId、runtimeGeneration、sessionId。插件仅向对应慢根 agent 调用同步 `agent.inject()`，下一 step 消费。`agent/turn-stopping` 直接等待快 lane 终态及其原始正文投递终态；最新快照尚未消费时注入衔接指令，继续同一 turn；消费后允许结束。等待保持原 runtime、session、调度名额和 running 状态，不增加执行阶段。真正执行结束后才调用 `endExecution()`。

快 lane 保留查询和取消工具限制，长任务简短承接，不否认整个 agent 的能力，不提前宣称完成。慢 lane 根据实际成功送达内容提供增量；没有增量可 `NO_REPLY`，反转结论必须回指并纠正。成功业务执行后允许 `no-increment` 静默；失败、空结果、未终结工具和需说明的附件须反馈。

面向用户的回复以“正在处理”“继续复核”和实际交付物描述衔接；lane、Task ID、outbox 与工作区路径是模型内部协作信息，不进入用户回复。

历史和观察窗口仅用于理解当前输入，其中其他 Task 的未完成承诺继续由原 Task 处理。准备的 prompt 明确区分背景与当前唯一 Task 输入，runner 和协作快照指令重复声明该归属；当前输入明确要求重做或追加时才据此执行，不因历史承诺接管旧任务或生成旧附件。live L14 将新短问的慢静默及附件归属作为独立语义断言，不依赖裁判将其判为严重还是轻微错误。

扩展静默结果为 v2，连带 Task 快照、管理器、runner、调度器、Actor、控制桥、输入准备、输出协调器和装配工厂迁移至版本化接口；v1 声明与消费者基线保留，不重新生成基线。持久化仍读取 v1 记录。

跨 lane 精确去重只依据成功送达的原始正文，重复分段按成功送达次数逐一匹配；入队幂等另用 Task/lane/结果/分段 ID。未送达的快答案不吞掉慢答案；附件独立保留。

## 等待与异常

沿用 `/stop`、存活提醒及 `slowTimeoutMs`，等待计入慢执行时限。取消、超时、通道关闭及服务关闭解除等待，清理监听、请求和计时器。快正文失败或超时保留异常，慢 lane 按真实送达情况答复。队列仍只尝试一次；没有合法出口的 pending 消息继续排队。

慢结果通过闸门入队后即可结算执行，不等待该慢消息自身送达。已入队消息取消后仍发送；重启不恢复执行。

## 验收

注入 DSH、连接器和时钟的离线 mock 覆盖同 turn 下一 step 消费、一次结算、完成顺序交换、分段和部分失败、pending、迟到消息、重复静默、增量、纠错、成功执行静默、失败与附件。等待时旧慢任务仍可取消和超时，新快任务可推进，关闭后资源归零。

O02/O03 增加正向协作样本，同时保留坏样本裁判校准。完整门槛为 `npm run check`；真实语义单列 `bench:session:live`，真实 WebSocket 单列 `test:integration`，离线结果不宣称模型语义保证。

## 实施记录

- `npm run check` 通过：55 个测试文件、1102 项通过；40 项 WebSocket 用例留给独立集成检查。17 项协作回归、O02C/O03C 正向 benchmark、原有坏样本校准及 36 个契约冒烟通过，类型、边界、v1 兼容、lint、格式、生成文档和 Docker 包解析全部通过。
- `npm run test:integration` 独立通过：3 个文件、104 项 localhost WebSocket 检查，不连接部署客户端。
- 回查配置：沿用快 30 秒、慢 30 分钟、提醒 5 分钟及双 lane 各 4 个 runtime；未增加执行阶段、整轮会话锁或配置项。等待中的取消/超时/通道关闭/服务关闭释放 runtime、监听器和计时器，pending 消息仍归独立队列保留。
- 生产公共工厂已迁移为 `create…V2`；v1 声明及 `compatibility/v1` 基线保留。此次只减少原有 ESLint 抑制项，没有增加抑制项。
- DeepSeek 官方 `bench:session:live` 已运行：快慢 flash、独立 v4-pro 裁判；L01/L02/L07/L08/L11/L14/L19 各一次，最终校准 6/6、运行 7/7、语义 7/7 和严格门禁通过，全部关闭资源为零。真实运行发现并修复了历史承诺导致新 Task 接管旧任务的问题，L14 v2 独立验证新短问慢静默与附件归属。最终报告见 [验收记录](../SESSION-BENCHMARK.md)，此前失败报告保留；默认 12 场景重复集和完整 24 场景尚未运行。
